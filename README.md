## Built with

Plain HTML, CSS and JavaScript, with no frameworks or build step. Fonts are Playfair Display and DM Sans from Google Fonts.

- Responsive layout that works from phones to wide screens
- Respects the system "reduce motion" setting
- Text colours meet WCAG AA contrast
- Images lazy-load

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
